Ветка "Дополнение-паттерна-фабричный-метод" конечный результат.
Мой личный курсовой проект с генератором уровней и готовыми уровнями. 
Хранение уровней в XML файлах. Движение на WASD.
После обновления драйверов на видеокартку rtx 3050 к сожалению полетели текстуры, возможно какая-то причина в совмести новых драйверов и OpenGL. 
Использоавался OpenGL 3.3, если не ошибаюсь.
